# Team Formatting Standards

## Horizontal Formatting
- **Indentation**: 4 spaces per level
- **Spacing**: Around operators and after commas
- **Line Length**: Max 120 characters
- **Alignment**: Natural flow, no column alignment

## Vertical Formatting
- **Newspaper Metaphor**: High-level methods first, details follow
- **Blank Lines**: Separate logical sections
- **Method Ordering**: Caller before callee

## Code Structure Order
1. Constants
2. Fields
3. Constructor
4. Public methods
5. Private helper methods

## Violations Fixed
- No spaces around operators/commas
- Multiple statements on one line
- No blank lines between sections
- Methods ordered randomly
